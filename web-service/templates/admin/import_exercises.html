Estructura CSV requerida:
Columnas recomendadas: uuid,question,options,correct_answer,explanation,difficulty,category,points,time_limit,hint,tags

uuid,question,options,correct_answer,explanation,difficulty,category,points,time_limit,hint,tags

Recomendaciones
  • Verifica el formato antes de importar
  • Haz backup de la base de datos primero
  • Importa en lotes pequeños primero

  • Revisa los logs después de importar
  • Los errores se guardarán en la base de datos
