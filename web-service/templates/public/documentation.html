Cómo funcionan las Lecciones

El curriculum esta organizado en temas que van desde lo basico hasta conceptos avanzados. Cada leccion incluye una explicacion clara, ejemplos de codigo y un ejercicio para practicar.

Estructura del curriculum
  • Variables y tipos de datos

    Strings, integers, floats, booleans y listas.

  • Operadores y expresiones

    Aritmeticos, comparacion, logicos y asignacion.

  • Condicionales

    if, elif, else y operador ternario.

  • Bucles

    for, while, range y comprensiones de listas.

  • Funciones

    Definicion, argumentos, retorno y scope.

  • POO y conceptos avanzados

    Clases, objetos, herencia y polimorfismo.

Ejemplo de leccion
'''Leccion 4: Condicionales'''

# Los condicionales permiten ejecutar codigo
# dependiendo de si una condicion es verdadera o falsa.

edad = 18

if edad >= 18:
    print("Eres mayor de edad")
elif edad >= 13:
    print("Eres adolescente")
else:
    print("Eres menor de edad")

# Salida: Eres mayor de edad
Tip: Puedes repetir cualquier leccion enviando /lesson [numero]. No hay limite de repeticiones.

Cómo funcionan los Ejercicios

Despues de cada leccion, el bot te propone ejercicios para practicar. Solo tienes que escribir tu codigo Python directamente en el chat y el bot lo evaluara al instante.

Proceso de un ejercicio
  1. El bot presenta el enunciado del ejercicio.
  2. Escribes tu codigo Python en el chat.
  3. El bot ejecuta y valida tu solucion.
  4. Recibes retroalimentacion inmediata: si es correcto o que debes mejorar.
Ejemplo: Ejercicio de Variables
# Enunciado:
# Crea una variable llamada "nombre" con tu nombre,
# y otra llamada "edad" con tu edad.
# Luego imprime: "Hola, me llamo [nombre] y tengo [edad] anos"

nombre = "Carlos"
edad = 25
print(f"Hola, me llamo {nombre} y tengo {edad} anos")
Correcto! Tu solucion es valida. Has completado el ejercicio 1 del tema Variables.
Ejemplo: Ejercicio de Condicionales
# Enunciado:
# Escribe un programa que determine si un numero
# es par o impar.

numero = 7

if numero % 2 == 0:
    print("Par")
else:
    print("Impar")
Intento fallido. El output esperado era "Impar" pero tu codigo produjo "Par". Revisa la logica de tu condicion.
Tip: Puedes intentar un ejercicio cuantas veces quieras. El bot te guiara hasta que lo resuelvas correctamente.
