Leccion: Condicionales
📚 Leccion 5: Condicionales
Los condicionales permiten ejecutar codigo
dependiendo de una condicion.
 
Ejercicio: Escribe un programa que diga
"Par" o "Impar" para un numero.
 
>>> numero = 7
>>> if numero % 2 == 0:
... print("Par")
... else:
... print("Impar")
 
✔ Correcto! Output: "Impar"
