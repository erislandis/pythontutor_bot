Problemas Comunes

  1. Verifica que tu conexion a internet este activa.
  2. Asegurate de haber enviado el comando /start al bot.
  3. Espera unos minutos y vuelve a intentar; el servidor puede estar temporalmente ocupado.
  4. Si el problema persiste, revisa el estado del sistema o contacta por Telegram.

Tu progreso esta vinculado a tu cuenta de Telegram y se guarda automaticamente. En raras ocasiones puede ocurrir:

  • Si cambiaste de cuenta de Telegram, el progreso no se transfiere automaticamente.
  • Contacta a soporte con tu usuario de Telegram para intentar recuperar datos recientes.

Recomendacion: usa el comando /stats periodicamente para verificar tu progreso.

  • Envia tu codigo como mensaje de texto plano, no como archivo adjunto.
  • Envuelve bloques de codigo en triple backticks (```) para un formateo correcto.
  • Evita enviar archivos .py; el bot espera codigo directo en el chat.
  • Revisa que no haya caracteres invisibles o espacios extra al inicio de cada linea.
